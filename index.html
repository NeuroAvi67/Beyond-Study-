Nutrient guide

Adult values from NIH Office of Dietary Supplements fact sheets. An RDA meets the needs of nearly all healthy people. An AI (adequate intake) is used when there’s no RDA. A UL is the highest daily intake unlikely to cause harm. Needs differ by age, sex and pregnancy, so this is education, not advice for you.

Calculators

Adult estimates (18+). Nothing here is a weight-loss prescription, and children and teens need age-specific growth references.

Meal tracker

Nutrients come from the food database, and totals are flagged when a food lacks a value. Entries are stored only in this browser (localStorage), not synced or secured on a server. For liquids, 1 ml is treated as 1 g.

Evidence explorer

Live research retrieval needs a backend or external API, which this page doesn’t have. So no individual papers are listed. These are verified portals where the original studies, guidelines and datasets live.

AI assistant

Ask nutrition-science questions with Google’s Gemini, using your own API key. Messages go from this browser straight to Google; nothing passes through NutriVerse. Answers are general education, can be wrong, and are not medical advice.

Create a key in Google AI Studio, restrict it to the Gemini API and set a spending limit. A saved key can be read by anyone who uses this browser profile. For a public site, route requests through your own server instead. Model names change, so edit the field if Google retires one.

General education only. It is not medical advice, can’t diagnose deficiencies from symptoms, and doesn’t replace a doctor or registered dietitian. Works offline once loaded; only external links and the AI assistant need internet.
